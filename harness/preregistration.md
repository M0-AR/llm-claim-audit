# E5 Preregistration: tool-less arithmetic harness

Registered: 2026-10-17, before any model contact.
Task set: `harness/tasks.json`, generated by `harness/gen_tasks.py` with seed
20261017 (40 tasks, 12-digit x 8-digit multiplication, multiplier digits 2-9
permuted). The generator is deterministic; the task file is committed and its
SHA-256 is recorded in `results/run_manifest.json`.

## Motivation

The video claims the default model experience has "no calculator" (claim C08).
A calculator-free language model must perform multi-digit arithmetic through
tokens alone. This harness tests whether tool-less chat completions can do
that reliably, and whether "thinking" variants change the picture.

## Hypotheses (fixed before execution)

- H1 (primary): a tool-less, non-thinking chat model solves fewer than 60% of
  the 40 tasks correctly (first integer in the reply is scored, no retries).
- H2 (secondary): a thinking-reasoning variant of the same model, scored the
  same way, beats the non-thinking variant. Test: exact McNemar on the paired
  outcomes (b and c discordant counts), two-sided, alpha = 0.05; report the
  exact binomial p-value computed with `math.comb`.
- H3 (exploratory): report a 95% bootstrap CI (seed 20261017, B = 10,000) for
  the accuracy difference, resampling tasks with replacement.

## Scoring rules (fixed)

- Prompt template is fixed in `tasks.json`; one message, no system prompt.
- A task is correct iff the first signed integer in the reply (commas ignored)
  equals the exact product. Anything else - refusals, partial answers, extra
  text before a wrong number - is incorrect. No retries, no fuzzy matching.
- Temperature 0 when the endpoint supports it.

## Execution protocol

```
OPENAI_API_KEY=... OPENAI_MODEL=<model> python3 harness/runner.py
python3 harness/score.py --a results/harness_thinking.jsonl --b results/harness_nonthinking.jsonl
```

`runner.py` exits with code 2 and does not call any API when `OPENAI_API_KEY`
is absent. In this public snapshot the harness is **registered but not
executed**: no API keys were available during the build, and that limitation
is disclosed in the README rather than papered over. The scorer is fully
offline and unit-tested against synthetic response files, so reproducing the
analysis requires only rerunning the two commands above.

## Analysis plan

- Report per-model accuracy with a Wilson 95% interval.
- For the pair, report b, c, the exact McNemar p-value, and the bootstrap CI
  of the accuracy difference.
- No model or task exclusions; all 40 tasks ship in the denominator.
